# Агрегаты «Будущего 2.0»

## Домен Клиники

### Агрегат: Пациент (Patient)
- **Корень агрегата**: Patient
- **Границы**: Управление персональными данными, медицинской историей, контактами.
- **Инварианты**:
  - Пациент должен быть уникален по полю `email` или `phone`.
  - Дата рождения не может быть в будущем.
  - Медицинские записи (MedicalRecord) принадлежат только одному пациенту.
- **Ключи**: `patientId` (UUID).
- **Вложенные сущности**: MedicalRecord, Contact, InsuranceInfo.
- **Доменные события**:
  - `PatientRegistered`
  - `PatientUpdated`
  - `PatientDeactivated`

### Агрегат: Приём (Appointment)
- **Корень агрегата**: Appointment
- **Границы**: Управление записью на приём, статусами, назначениями.
- **Инварианты**:
  - Время приёма не может пересекаться для одного врача.
  - Статус приёма изменяется последовательно: `SCHEDULED` → `IN_PROGRESS` → `COMPLETED` / `CANCELLED`.
  - Приём должен быть связан с пациентом и врачом.
- **Ключи**: `appointmentId` (UUID).
- **Вложенные сущности**: AppointmentSlot, Diagnosis, Prescription.
- **Доменные события**:
  - `AppointmentCreated`
  - `AppointmentStarted`
  - `AppointmentCompleted`
  - `AppointmentCancelled`

### Агрегат: Исследование (Examination)
- **Корень агрегата**: Examination
- **Границы**: Управление медицинскими исследованиями (лаборатория, инструментальные).
- **Инварианты**:
  - Исследование не может быть выполнено без назначения.
  - Результат исследования может быть изменён только до подтверждения (`CONFIRMED`).
  - Для ИИ-исследований результат должен быть получен из ИИ-сервиса.
- **Ключи**: `examinationId` (UUID).
- **Вложенные сущности**: ExaminationResult, Attachment (снимки, файлы).
- **Доменные события**:
  - `ExaminationOrdered`
  - `ExaminationStarted`
  - `ExaminationCompleted`
  - `ExaminationResultConfirmed`

## Домен Финтех

### Агрегат: Кредит (Loan)
- **Корень агрегата**: Loan
- **Границы**: Управление кредитными договорами, выплатами, процентами.
- **Инварианты**:
  - Сумма кредита не может превышать лимит клиента.
  - Статус кредита изменяется по цепочке: `APPLIED` → `APPROVED` → `ACTIVE` → `CLOSED` / `DEFAULTED`.
  - Проценты пересчитываются ежемесячно.
- **Ключи**: `loanId` (UUID).
- **Вложенные сущности**: LoanPayment, InterestRate, Collateral.
- **Доменные события**:
  - `LoanApplied`
  - `LoanApproved`
  - `LoanActivated`
  - `LoanPaymentMade`
  - `LoanClosed`
  - `LoanDefaulted`

### Агрегат: Счёт (Account)
- **Корень агрегата**: Account
- **Границы**: Управление банковскими счетами, балансами, транзакциями.
- **Инварианты**:
  - Баланс счёта не может быть отрицательным (для некоторых типов счетов).
  - Транзакции должны быть атомарными.
  - Каждый клиент может иметь несколько счетов.
- **Ключи**: `accountId` (UUID).
- **Вложенные сущности**: Transaction, AccountType, Balance.
- **Доменные события**:
  - `AccountOpened`
  - `AccountClosed`
  - `TransactionMade`
  - `AccountFrozen`

## Домен ИИ-сервисы

### Агрегат: Модель (Model)
- **Корень агрегата**: Model
- **Границы**: Управление ML-моделями, версиями, метриками.
- **Инварианты**:
  - Модель должна иметь версию и состояние (`TRAINING`, `VALIDATED`, `DEPLOYED`).
  - Метрики качества модели должны быть заданы.
- **Ключи**: `modelId` (UUID).
- **Вложенные сущности**: ModelVersion, Metric, TrainingRun.
- **Доменные события**:
  - `ModelDeployed`
  - `ModelRetrained`
  - `ModelArchived`

### Агрегат: Диагноз ИИ (AIDiagnosis)
- **Корень агрегата**: AIDiagnosis
- **Границы**: Результаты ИИ-диагностики, рекомендации.
- **Инварианты**:
  - Диагноз ИИ требует подтверждения врачом.
  - Результат должен содержать уверенность (confidence score).
- **Ключи**: `diagnosisId` (UUID).
- **Вложенные сущности**: AIDiagnosisResult, Recommendation.
- **Доменные события**:
  - `AIDiagnosisRequested`
  - `AIDiagnosisCompleted`
  - `AIDiagnosisConfirmed`
  - `AIDiagnosisRejected`

## Домен Аналитики

### Агрегат: Витрина данных (DataMart)
- **Корень агрегата**: DataMart
- **Границы**: Управление аналитическими данными, агрегатами, витринами.
- **Инварианты**:
  - Данные должны быть консистентны (согласованы по времени).
  - Витрина не содержит медицинских карт и исследований (только агрегированные данные).
  - Доступ к данным разграничен по ролям.
- **Ключи**: `datamartId` (UUID).
- **Вложенные сущности**: Dataset, Aggregate, Report.
- **Доменные события**:
  - `DataMartUpdated`
  - `ReportGenerated`
  - `DataMartRefreshed`

### Агрегат: Отчёт (Report)
- **Корень агрегата**: Report
- **Границы**: Формирование и доставка отчётов.
- **Инварианты**:
  - Отчёт должен быть уникален по имени и дате.
  - Доступ к отчёту ограничен уровнем доступа пользователя.
- **Ключи**: `reportId` (UUID).
- **Вложенные сущности**: ReportFilter, Visualization, Schedule.
- **Доменные события**:
  - `ReportCreated`
  - `ReportScheduled`
  - `ReportDelivered`
