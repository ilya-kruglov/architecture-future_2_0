# Расширенный технический радар «Будущее 2.0»

## Легенда
- **Adopt** – активно используем, рекомендуем для новых проектов.
- **Trial** – пилотируем, оцениваем пригодность.
- **Assess** – изучаем, планируем эксперименты.
- **Hold** – не рекомендуется, планируем замену или отказ.

| Категория | Технология | Статус | Примечание |
|-----------|------------|--------|------------|

## Архитектурные паттерны

| Паттерн | Статус | Применение |
|---------|--------|------------|
| **Event-Driven Architecture** | Adopt | Основа интеграции между доменами через Kafka |
| **Data Mesh** | Trial | Децентрализованное владение данными по доменам (пилот) |
| **Domain-Driven Design (DDD)** | Adopt | Стратегическое и тактическое проектирование |
| **Self-service BI** | Adopt | Портал с возможностью конструирования отчётов |
| **Anti-Corruption Layer (ACL)** | Adopt | Для интеграции с легаси-системами (Camel, DWH) |
| **CQRS / Event Sourcing** | Assess | Для отдельных агрегатов (например, кредиты, счета) |
| **Strangler Pattern** | Adopt | Постепенное замещение легаси-систем |
| **Chaos Engineering** | Assess | Повышение отказоустойчивости |
| **Federated Governance** | Assess | Для управления доменами в Data Mesh |
| **Data Product Ownership** | Trial | Введение ролей владельцев данных |

## Заключение
Технологический радар отражает стратегический выбор «Будущего 2.0»: переход к событийно-ориентированной архитектуре, использование облачных managed-сервисов, внедрение Data Mesh и self-service аналитики. Легаси-технологии (PowerBuilder, SQL Server 2008, Camel) помечены как Hold и будут постепенно выведены.
